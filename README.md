# zukeLightweight

A Fabric mod for Minecraft 26.3 by **zrp8858**.

**Status: work in progress -- nothing released yet.**

Mostly-vanilla quality-of-life features, entirely client side: install it
locally and it works in singleplayer and on any server, no server-side install
needed.

## Requirements

- Minecraft 26.3
- [Fabric Loader](https://fabricmc.net/use/) 0.19.5+
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [malilib](https://modrinth.com/mod/malilib) (config screen and hotkeys)
- [Mod Menu](https://modrinth.com/mod/modmenu) (optional; adds a "Configure" button)
- Java 25
